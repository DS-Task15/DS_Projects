# Dataset dictionary

`customer_reviews.csv` contains 300 synthetic educational reviews.

- `review_id`: unique row identifier
- `review_text`: input review
- `aspect`: Battery, Camera, Shipping, Price, or Build Quality
- `sentiment`: Positive, Negative, or Neutral

There are 60 examples per aspect and 100 per sentiment. Synthetic data demonstrates code only; it is not real customer feedback.
